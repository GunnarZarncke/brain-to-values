# Minimal self-pointer experiment

This experiment tests a narrow mechanistic hypothesis:

> A privileged low-bandwidth internal signal about an orienting reaction can become bound to one entity in an otherwise symmetric world model, yielding a persistent latent variable functionally equivalent to “which body is me?”.

It does **not** test consciousness.

## Environment

Each episode contains two visually identical candidate bodies following independent trajectories generated by the same dynamics and command distribution. The input is object-centric rather than pixels; simple body→flash and body→target relative vectors are included so the experiment tests self-binding rather than spending most capacity rediscovering elementary geometry. A physical world is duplicated into a matched counterfactual pair:

- in row A, candidate 0 is designated self;
- in row B, candidate 1 is designated self;
- the entire visual history is exactly identical.

At the final timestep a target is placed between the two bodies along the x-axis. The left body must move right and the right body must move left. Thus the two counterfactual selves have exactly opposite binary actions in an identical visual scene, and vision alone cannot exceed 50% on the matched pairs.

During an identification phase the network may receive selected privileged cues:

1. **Orienting / Steven cue**: a one-bit signal saying whether the current flash triggered *this organism's* orienting response. The visual stream contains the flash and both bodies but does not say which body is self.
2. **Efference copy**: the motor command belonging to the self body. Both candidate bodies have iid command streams, so only temporal action→motion matching identifies self.
3. **Proprioception**: the self body's displacement vector, which must be matched to one visual trajectory.
4. **Explicit self ID**: a direct one-hot visible-token identity, used only as an upper bound.

The final decision timestep contains no orienting/efference/proprio cue. The model must use persistent state accumulated earlier.

## Network

`SelfPointerNet` is deliberately small and inspectable:

visual tokens → transformer → recurrent bottleneck `z` → `z` injected back into token processing → transformer → final action

The injection of `z` is the recirculation path. The model can also optionally expose `z` directly to the policy head. This supports a three-way architectural comparison: **recirculation-only**, **state-to-policy-only**, and **both**. The first forces persistent self information to alter object representations before it can affect the decision; the second is a standard recurrent-memory control.

## Ablations

`train.py --experiment all` trains:

- `vision_only`
- `orient_only`
- `efference_only`
- `proprio_only`
- `orient_efference`
- `orient_proprio`
- `all_internal`
- `explicit_self`

`run_ablation.py` additionally compares recirculation-only, direct-state-only, and both routes for `orient_only` and `all_internal`.

## Measurements

The code reports four different signatures.

### 1. Task accuracy

Can the model choose left vs. right appropriately for the hidden self in matched visual worlds?

### 2. Recurrent-state self probe

A post-hoc linear probe predicts which candidate body is self from `z_t` at each timestep.

### 3. Object-level self probe

A linear probe predicts whether each candidate-body token is self. This tests whether self information has become embedded in perceptual object representations rather than merely stored in a global hidden state.

### 4. Causal state swap

For a matched counterfactual pair, the recurrent state is swapped immediately before the final target frame while leaving the visual world unchanged. If `z` causally carries the self pointer, the prediction should move toward the counterpart's correct action.

`state_swap_counterfactual_accuracy` scores the patched prediction against the *other self's* label. High ordinary accuracy and high swapped-counterfactual accuracy is substantially stronger evidence than decoding alone.

## Expected qualitative pattern

The intended falsifiable pattern is approximately:

- vision-only ≈ chance (50% on matched pairs);
- orient-only > chance after a delayed phase transition;
- efference-only and proprio-only > chance given sufficient training (weak at 300 rounds in current runs);
- combined cues ≥ orient-only at convergence, with clearer advantage early in training (report means over multiple seeds);
- explicit-self gives the upper bound;
- self information appears first in `z`, and with recirculation becomes more decodable from candidate-object tokens;
- swapping `z` changes the inferred self and hence the final action.

A failure of orient-only to support persistent self inference, while motor/proprioceptive cues work, is evidence against the proposed role of the orienting signal in this architecture rather than something to tune away.

## Important interpretation

The latent variable is deliberately not supervised as “self”. It is useful because the same visible world requires opposite decisions depending on which physical trajectory is the privileged source of internal signals and reward consequences. The experiment tests whether heterogeneous privileged signals converge on a reusable entity binding.

## Why supervised training first?

The current implementation trains the final control action with cross-entropy rather than policy-gradient RL. This is deliberate: the self variable is **not** supervised, while the simple downstream action is. It removes exploration and credit-assignment noise from the first test of whether privileged cues produce a persistent entity binding. If the representational effect survives the ablations, replacing the final imitation/control loss with environmental reward is the natural next step.

The paired construction is particularly useful here: every physical world contributes both self assignments, so a cue-free learner sees two identical visual sequences with opposite labels. This gives a hard 50% ceiling without relying on approximate balancing.
